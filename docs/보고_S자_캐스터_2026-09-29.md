# S자 주행 · 캐스터 문제 정리 (2026-09-29)

## 1. S자로 들어가고 나오던 문제

**원인**
- 캐스터가 차체를 살짝 돌리면 로봇이 늦게 알아채고 크게 되돌렸다. 그 되돌림이 반복되면서 S자가 됐다.
- 늦었던 이유는 두 가지다.
  - 천천히 갈 때는 "급회전 금지" 제한 때문에 방향을 조금밖에 못 틀었다.
  - 나올 때 좌우 5~12mm 어긋난 것까지 고치려다 좌우로 왔다 갔다 했다.
- 모터 명령 한 줄이 통신 중에 빠지면, 한쪽 바퀴가 아주 조금 빠르게 도는 상태가 계속 남았다. 그래서 1.2m 가는 동안 8~10° 휘었다.

**해결**
- 도킹할 때는 급회전 제한을 풀고, 자이로로 차체가 돌기 시작하는 순간 바로 반대로 잡게 했다.
- 나올 때는 좌우는 고치지 않는다. 방향만 한 번 맞추고 곧게 나온다.
- 모터 명령을 값이 같아도 0.2초마다 다시 보낸다. 한 줄이 빠져도 0.2초 안에 복구된다.

## 2. 캐스터 문제

**원인**
- 앞으로 가다 뒤로(또는 뒤로 가다 앞으로) 출발하면 캐스터가 180° 뒤집힌다. 이때 차체가 3~4° 돌아간다.
- 뒤집히는 구간은 출발 후 10~20cm이고, 빠를수록 제어가 따라가지 못한다.
- 어느 쪽으로 돌지는 매번 다르다. 그래서 "미리 반대로 돌아 두기"를 해 봤더니 캐스터가 반대쪽으로 튀었다. 이 방법은 꺼 두었다.

**해결**
- 방향을 바꿔 출발할 때 처음 25cm는 천천히(0.04m/s) 가면서 방향만 붙잡는다. 캐스터가 다 뒤집힌 뒤에 속도를 올린다.
- 도킹이 끝나면 앞으로 4cm 살짝 가서 캐스터를 미리 앞쪽으로 돌려 둔다.
- 효과가 없었던 방법도 있다.
  - 모터 반응 올리기: 속도가 처질 때 더 세게 밀도록 드라이브 적분값을 8에서 64로 올렸다. 튐이 100초당 5.7건에서 5.1건으로 거의 그대로였다. 해가 없어 64로 두었고, 펌웨어에 넣어 전원을 꺼도 유지된다. 비례값은 35에서 60으로 올리자 조향이 더 심해져 35로 되돌렸다.
  - 최대 전류(토크 한계)는 31A 그대로 두었다. 튈 때 실제 전류가 1~6A라 힘이 모자란 게 아니었다.
  - 구동륜 쪽에 무게를 더해도 달라지지 않았다.

## 결과 (렉2 기준)

| 항목 | 전 | 후 |
|---|---|---|
| 들어갈 때 방향 흔들림 | 약 6° | 약 3° |
| 나올 때 튐 | 3~4° | 1.5° 이하 |
| 도킹 시간 | 34초 | 35초 (진입 0.16m/s, 나오기 0.12m/s로 올림) |
| 성공률 | — | 최근 15회 연속 성공 |

## 남은 과제

- 캐스터가 차체를 미는 것 자체는 부품 문제라서 소프트웨어로는 줄이는 것까지만 된다. 캐스터 교체 같은 하드웨어 검토가 필요하다.
